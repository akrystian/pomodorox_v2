PROTOTYPLogika timera Pomodorox

Pytanie: czy model stanów timera jest dobry? Sprawdzamy start, pauzę, wznowienie, stop, przełączanie sesji z potwierdzeniem, zamknięcie i ponowne otwarcie aplikacji po upływie czasu, blokadę Active Task w trakcie pracy, licznik Pomodoro i Event Log. Czas jest symulowany: przesuwasz go przyciskami „+ minuty”. Uruchom scenariusz z zakładek albo klikaj dowolnie. Szukaj momentów typu „chwila, to nie powinno być możliwe”.
